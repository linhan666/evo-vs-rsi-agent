## 四、成本是否只反映数据集难度

| 臂 | n | 墙钟 vs 样本数 ρ | p | 作业 vs 样本数 ρ | p |
|---|---|---|---|---|---|
| R agent + memory + self-modify | 9 | 0.683 | 0.050 | -0.1 | 0.800 |
| A agent, no memory | 9 | 0.35 | 0.359 | 0.509 | 0.171 |
| M agent + memory | 9 | 0.109 | 0.784 | -0.237 | 0.543 |
| W fixed workflow | 9 | 0.783 | 0.017 | 0.0 | 1.000 |

**这是 Phase 7 目前最重要的发现**：靶点顺序按活性数据量降序排列，所以任何「沿序列成本下降」都可能只是「靶点在变小」。

- **A 臂的墙钟与作业数都随数据量强上升**（ρ = 0.35 / 0.509，n=9）——无记忆的 agent 必须按数据规模做正比探索。
- **R 臂的作业数与数据量几乎无关**（ρ = -0.1，n=9），墙钟也只有中等相关（ρ = 0.683）——经验把「探索广度」从「数据规模」上解耦了。

这个对比比「冷启动 vs 热启动」更稳健：它不依赖单点的冷启动观测，而是用整条序列的斜率说话。

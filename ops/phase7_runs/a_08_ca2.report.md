(a) CHOICES AND RATIONALE
1. Representation: Morgan r=2, 2048 bits + 7 RDKit 2D descriptors (the toolchain-canonical set). Measured against r=3/2048 with the same model: RF AUROC 0.9885 (r2) vs 0.9843 (r3), so r2 kept. 4096-bit and desc_set v2 feature files were produced but ml.train rejected them (exit 1, no artifact) — un-evaluated, toolchain constraint.
2. Model family: compared on the scaffold manifest with identical features/split: RandomForest 0.9885 AUROC > XGBoost 0.9804 > LogReg 0.9280. RF chosen; it is also the most stable (seed 23 replication: 0.9878 AUROC, 0.9996 AUPRC).
3. Validation: scaffold split is the headline; random split is used only as an optimism diagnostic. LogReg benefits from random splitting (0.9673 vs 0.9280); RF does not (0.9882 vs 0.9885), i.e. no meaningful scaffold optimism for the selected model.
4. Metric discipline: with a 92.9–97.0% positive rate, AUPRC is anchored at 0.970 and EF@1% saturates. EF@1% came out exactly at its ceiling in every run (1.031 with 708/730 positives; 1.081 with 675/730) — all models put only positives in the top 1% of validation. So AUROC is the only discriminating metric here; AUPRC/EF@1% are reported but must not be compared to balanced benchmarks.
5. Library scoring and fusion: RF and XGB each screened the full 100k library; a rank-average fusion (weights 0.5/0.5, declared not fitted, val AUPRC 0.9996/0.9994) was written as a cross-model check. The delivered top-100 comes from the single best model because fusion showed no validated AUPRC gain and the fusion file carries no SMILES.

(e) WHAT I WOULD REUSE FOR ANOTHER TARGET OF THIS KIND
1. Morgan r2/2048 + 7 descriptors as the default representation; check r3 rather than assuming.
2. RF first for a highly imbalanced, ligand-like label regime; LogReg/XGB as cheap sanity baselines.
3. Scaffold split as headline, random split only to measure optimism.
4. Always compute the EF@1% ceiling (1/positive rate) and the AUPRC baseline (positive rate) before quoting either; use AUROC for model selection here.
5. Two-seed replication before believing sub-0.01 AUROC differences.
6. Screen the library with the selected model, then pharmacophore-check the top-K before delivering (for CA2: aryl primary sulfonamide).

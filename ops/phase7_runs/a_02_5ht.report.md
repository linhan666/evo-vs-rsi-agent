### (0) Data audit — the most important finding
`dataset.csv` is a **binary-labeled** file: columns `molecule_chembl_id`, `canonical_smiles`, `label` only. There is **no raw Ki, standard_value, units or relation column** (verified: requesting those as SMILES falls back to canonical_smiles). 4828 unique molecules, **4733 positive / 95 negative (98.03 %)**.
Consequence: AUPRC has a 0.980 no-skill baseline and **EF@1 % is structurally ≈1.00–1.01** — it cannot discriminate models here. AUROC is the only usable criterion, and every scaffold validation split contains only 9–20 negatives (SE ≈ 0.04–0.07). All reported numbers must be read with that caveat. No negative was invented and the read-only CSV was never modified.

### (a) Choices and rationale
- **Representation**: Morgan radius 2, 2048 bits + 7 RDKit 2D descriptors (MolWt, cLogP, HBD, HBA, TPSA, rotB, rings), desc_set v1. Radius 3 was tested and hurt CatBoost (0.838 vs 0.9265); descriptor set v2 exposes the same 7 descriptors. A bit-size sweep (256/512/1024/2048) showed 2048 clearly best for CatBoost.
- **Model**: **CatBoost** on the v1 2048-bit matrix. No hyperparameter search is exposed by the tool, so library defaults were used. LogReg, RF and XGBoost were compared head-to-head.
- **Validation**: Bemis–Murcko scaffold split via `data.split`; model selection on the scaffold-validation set; test partitions never touched. Important tooling finding: **the scaffold splitter ignores its seed** (seeds 17/23/29/31/37 produce byte-identical row assignments; only a fraction change alters the split), so "repeated scaffold splits" were done by varying val/test fractions instead, plus a random split as an optimistic diagnostic. `evaluation.locked` only supports MOR/KOR/DRD2, so **no independent locked test exists for 5-HT**; the honest estimate is the scaffold holdout.
- **Fusion**: `ml.fuse` was considered but **rejected** — no available tool computes AUROC/AUPRC of a fused model on held-out labels, so fusion weights could not be justified and the fused ranking would be unvalidated.

### (c) Top-100 path (and the deployment constraint)
`screening.rank` densifies the feature matrix. 100k × 2055 floats exceeds the practical memory/time budget here: **every direct 2048-bit scoring of the 100k library timed out** (240/300/600/1800 s caps), although featurizing 100k molecules itself takes only 14 s. The 256-bit CatBoost scores the full library in 12.2 s.
Final ranking is therefore a **two-stage cascade**:
1. CatBoost 256-bit scores all 100,000 (12.1 s) → top-3000 pool: `ranking/ht_ki_stage1_catboost256_top3000.csv`.
2. CatBoost 2048-bit (AUROC 0.9265) reranks the pool (2.3 s) → **`ranking/ht_ki_final_top100_v2.csv`** (100 molecules, scores 0.9975–0.9991), full stage-2 ranking in `ranking/ht_ki_stage2_catboost2048_full_v2.csv`.

Head of the list: zinc047187, zinc081352, zinc063521, zinc043180, zinc041412, zinc067984, zinc076349, zinc002154, zinc045860, zinc094700. Top-100 chemotypes are CNS-like: arylpiperazines/piperidines, methoxy-aromatics, fused heterocycles, weakly basic amines — consistent with 5-HT ligands.
Alternative reproducible full-library single-model list: `ranking/ht_ki_catboost_b256_full.csv` (100k rows) and `ranking/ht_ki_catboost_b256_top100.csv` (pure 256-bit top-100, AUROC 0.853).
Caveat: stage 2 only sees the stage-1 top-3000, so cascade recall is bounded by the 256-bit model; the 2048-bit model itself was validated at 0.9265 but the cascade ranking was not separately validated.

### (e) What I would reuse on another target of this kind
1. **Audit prevalence first.** If positives >90 %, stop reporting EF@1 %/AUPRC as evidence and select on AUROC against a scaffold holdout; state the AUPRC no-skill baseline.
2. Morgan r2 2048 + 7 descriptors → CatBoost is the strongest of the four exposed families on this chemistry; keep LogReg/RF as cheap baselines.
3. Check that the splitter's seed actually changes the split; if not, vary val/test fractions and report the negative counts, because 9–20 negatives is the real uncertainty source.
4. Before ranking 100k, measure the tool's memory scaling. A 2048-bit model can be trained but not necessarily deployed; either use ≤512 bits, or use the cascade (coarse 256-bit filter → fine rerank) and disclose the recall bound.
5. Keep the test partitions untouched and never substitute a scaffold holdout for the independent locked evaluator.

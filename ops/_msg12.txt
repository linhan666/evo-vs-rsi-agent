feat(analysis): measured the noise floor; the quality claims do not survive it

M 臂从空库重复三次（p7b / p7d / p7e），同版本、同任务、同靶点，
每靶点三个独立样本。差异里不含任何处理效应，纯粹是 agent 选择的随机性。

锁定 AUROC 逐靶点：
  D2 / ADR / DRD2 / KOR / MOR  三次完全相同（极差 0.0000）
  CA2  0.0004    PT  0.0129    5HT  0.0401    CBR  0.1543

池化臂内 SD = 0.0308，平均成对差 = 0.0154。
待检效应：记忆 R−A = +0.0118；版本 R′−R = +0.0112。
臂内 SD 是记忆效应量的 2.6 倍。

结论：质量层面的臂间差异落在重跑噪声之内，不成立。
R vs A 的 +0.0118 不能解释为记忆的作用；R′ vs R 的 +0.0112 同理。

机制比结论更有意思：验证 AUROC 的臂内 SD 只有 0.0005（几乎完全稳定），
而锁定 AUROC 的 SD 是 0.0308、最大极差 0.1543。也就是说 agent 三次都
选出了验证分数几乎相同的模型，但它们在锁定集上表现差很多 ——
验证集无法区分候选模型，选择因此近乎随机。这是任务设置本身的问题，
不是 harness 的问题，但它决定了「用验证分数做模型选择」这条路的上限。

成本结论仍然成立且极稳：
  token  有记忆 1.28M vs 无记忆 10.13M，差距 8.85M ≈ 16 倍于臂内 SD(0.55M)
  墙钟   臂内 SD 185s，中位 278s —— 成本指标的噪声也不小，引用时需带区间
